# Stok Ku — Backend API

Direktori ini berisi REST API Laravel untuk aplikasi Stok Ku.

Panduan instalasi lengkap, konfigurasi lingkungan, daftar endpoint, pengujian, dan build produksi tersedia di [README utama proyek](../README.md).

Perintah singkat untuk pengembangan:

```powershell
composer install
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Pengujian backend:

```powershell
php artisan test
```
